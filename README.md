# NextMove TX

A free tool for Texans in a bind. Tap what you need (car, rent, light bill, food, house repairs, credit, SSDI) and get **who to call, what to say, and what to have ready**.

- Free. No signup, no ads.
- Nothing is saved or sent. It all runs in your browser.
- Not a lender. It never asks for money.

**Use it:** https://porkjelly77.github.io/nextmove-tx/
